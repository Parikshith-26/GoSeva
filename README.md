# GoSeva Tracker 🐄

GoSeva Tracker is a smart cattle health and milk yield management application designed for small-scale farmers. The app helps farmers digitally manage livestock records, monitor milk production, track vaccinations, and receive AI-powered insights for better cattle care and productivity.

---

## 🚀 Features

* 📋 Digital cattle health records
* 💉 Vaccination and medical tracking
* 🥛 Milk yield monitoring and analytics
* 📍 Location and farm management
* 📷 Camera support for cattle records
* 🤖 AI-powered insights using Gemini AI
* 📱 Android mobile app support using Capacitor
* 🌐 Offline-friendly functionality

---

## 🛠 Technologies Used

* React
* Vite
* TypeScript
* Capacitor
* Android Studio
* Tailwind CSS
* Firebase
* Gemini AI API

## ⚙️ Installation

### Prerequisites

* Node.js
* Android Studio
* Java JDK 17+

---

## 📦 Run Locally

### 1. Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
cd GoSeva-Tracker
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Create Environment File

Create `.env.local`

```env
GEMINI_API_KEY=your_api_key_here
```

---

## ▶️ Start Development Server

```bash
npm run dev
```

App runs on:

```bash
http://localhost:3000
```

---

## 📱 Run Android App

### Add Android Platform

```bash
npx cap add android
```

### Sync Project

```bash
npm run mobile:sync
```

### Open Android Studio

```bash
npm run mobile:open
```

---

## 🏗 Build APK

In Android Studio:

```text
Build → Build APK(s)
```

Generated APK location:

```text
android/app/build/outputs/apk/debug/
```

---

## 🎯 Problem Statement

Small-scale farmers often struggle to maintain organized cattle health records, vaccination schedules, and milk production tracking. GoSeva Tracker digitizes livestock management and provides centralized monitoring with AI-powered assistance for improved productivity and animal care.
